Meeresschule · Stand: 14. Oktober 2026

Die Meeresschule ist ein Lernspiel für Kinder von 3 bis 5 Jahren, entwickelt von Tolga Samahor. Die Privatsphäre von Kindern ist wichtig, deshalb ist die App so gebaut, dass sie überhaupt keine personenbezogenen Daten erhebt.

Kurz gesagt

  • Es werden keine personenbezogenen Daten erhoben, auf einem Server gespeichert oder weitergegeben.
  • Keine Werbung, keine Analyse und kein Tracking.
  • Keine Konten, keine Registrierung, keine Anmeldung.
  • Kein Zugriff auf Kamera, Mikrofon, Standort, Kontakte oder Fotos.
  • Das Spiel nutzt kein Internet. Nur Käufe und Wiederherstellungen laufen über den App Store oder Google Play.

Was auf dem Gerät bleibt

Damit das Spiel funktioniert, werden einige Angaben ausschließlich auf Ihrem Gerät gespeichert: gesammelte Sterne und Stufen, die Einstellungen für Sprache, Ton und Musik sowie die Information, ob die Vollversion freigeschaltet ist. Diese Angaben werden nie an uns oder Dritte gesendet. Sie können in Ihren Gerätesicherungen (z. B. iCloud) enthalten sein und werden gelöscht, wenn Sie die App löschen. Den Fortschritt können Sie auch in den Einstellungen zurücksetzen.

Käufe

Die Vollversion wird über den App Store (iOS) oder Google Play (Android) gekauft. Ihre Zahlungsdaten verarbeitet der Store; sie erreichen uns nie. Der Kaufbildschirm liegt hinter einer Elternsperre.

Kinder

Wir erheben wissentlich keine personenbezogenen Daten von Kindern. Einstellungen und Käufe sind durch eine Elternfrage geschützt, für die man lesen können muss. Die App enthält keine externen Links, keine Social-Media-Funktionen und keinen Chat.

Dritte

Die App enthält keine Werbe-, Analyse- oder Tracking-Tools von Drittanbietern, und es werden keine Daten an Dritte weitergegeben.

Diese Website

Diese Website wird auf GitHub Pages gehostet und verwendet keine Cookies und keine Analyse. GitHub kann beim Ausliefern der Seiten technische Protokolle wie IP-Adressen speichern; siehe die Datenschutzerklärung von GitHub.

Änderungen

Wenn sich diese Erklärung ändert, wird diese Seite aktualisiert und das Datum oben angepasst.
